# 问财（iWencai）Query 模板库 · CAN SLIM 七要素取数

> 本文档是 SKILL.md 取数部分的展开：给出每个要素对应的问财自然语言 query 模板、可能返回的字段名、以及已知的**数据缺口与替代方案**。
> 按需加载：当需要构造具体 query、或某要素取不到数据时读取。
>
> 调用方式（任一 hithink skill）：
> ```bash
> python3 ~/.claude/skills/hithink-{finance|market|zhishu}-query/scripts/cli.py \
>   --query "<中文问句>" --limit 20
> ```
> 三个 skill 共享同一问财 endpoint，仅 `X-Claw-Skill-Id` header 不同。返回 `datas` 数组，**字段名动态**。

---

## 总原则：问财字段是动态的

问财是**自然语言接口**：你问什么，它解析后返回对应字段。同样的语义有多种问法，返回字段名也可能不同（如"净利润同比增长率" vs "净利润增速" vs "归母净利同比"）。因此：

1. **不要假设固定字段名**——本表的"可能字段"只是参考。
2. **拿不到就换问法**——先用更简单/直接的 query 重试，再用 `--call-type retry`。
3. **辅助脚本 `canslim_screener.py` 已做关键字容错归类**，匹配不上的字段会进"其他"列，不丢信息。

## 各要素 Query 模板

### C — 当季收益（finance）
```
最近一季净利润同比增长率大于25%的股票
最近一季营业收入同比增长大于25%的股票   ← 销售额要求（✅已实测，返回"营业收入同比增长率[报告期]"）
单季度归母净利润同比增长超过40%
最新一期季报净利润同比
```
- 可能字段：`最新一期净利润同比增长率`、`单季净利润同比增长`、`归母净利润同比`、`单季营业收入同比`
- ⚠️ **缺口**：问财多返回"净利润"而非"每股收益 EPS"。用净利润同比近似 C，注意排除增发稀释大的公司。
- ⚠️ **原书要求盈利与销售双达标**（或销售额近三季逐季加速）：两条 query 各跑一次取交集，纯"增收不增利/增利不增收"都打折扣。

### A — 年度收益（finance）
```
连续3年净利润同比增长的股票
近三年净利润复合增长率大于25%
近三年净利润同比增长且ROE大于17%
近三年经营现金流与净利润比值大于1的股票 ← 盈利质量（✅已实测，返回三年经营现金流净额序列）
```
- 可能字段：`近三年净利润同比增长`、`净利润复合增长率`、`ROE`、`净资产收益率`、`经营现金流`、`净现比`
- ✅ ROE 可直接取。
- 💡 原书 A 章盈利质量标准：每股经营现金流 ≥ 每股收益（正常年份约 200%）；可用"净现比/经营现金流÷净利润"近似检查。

### N — 新高 / 涨幅（market）
```
股价创52周新高的股票
创历史新高的股票
近一年涨幅排名
```
- 可能字段：`是否创52周新高`、`是否创历史新高`、`近一年涨跌幅`
- ⚠️ **缺口**：**"新催化剂"问财查不到**（新产品/新管理/新景气），必须人工补充新闻与研报。

### S — 供需 / 量价（market）
```
量比大于1.5且换手率大于3%的股票
放量上涨的股票（近5日成交量放大）
流通市值小于500亿
资产负债率小于50%且ROE大于17%的股票（finance） ← 低负债（✅已实测，复合条件可解析）
```
- 可能字段：`量比`、`换手率`、`成交量`、`流通市值`、`资产负债率`
- ⚠️ **缺口**：**量价关系**（如"杯柄突破放量 / 回调缩量 dry-up"）是综合判断，问财只给基础字段，需自行组合判断。
- 💡 原书 S 章还查**回购/增减持公告**与**举债回购**——问 cninfo 或公告接口。

### L — 领涨强度（market）
```
近6个月涨幅排名前10%的股票
近3个月涨幅最大的股票
行业指数近6个月涨幅排名               ← 强势行业组（✅已实测，返回410个行业指数区间涨幅；勿用"申万一级行业涨幅"问法，返回0）
```
- 可能字段：`指数简称`、`涨跌幅[区间]`、`近三月涨跌幅`、`近六月涨跌幅`、`近十二月涨跌幅`
- ⚠️ **缺口**：**IBD RS Rating（1–99 专有评分）问财无**。用"近 6/12 月涨幅在同行业的百分位"替代（前 20% ≈ RS≥80）。
- 💡 双层判断：先确认**行业组本身在市场涨幅前列**（用"行业指数近6个月涨幅排名"），再确认个股在**组内前 1–2 名**——"最强行业里的最强个股"（原书：约 2/3 大牛股出自最强行业组）。

### I — 机构持仓（market / finance）
```
主力资金连续5日净流入的股票（market）
基金持股比例排名（finance）
机构持股比例增加的股票（finance）
```
- 可能字段：`主力净流入`、`主力净流入额`、`基金持股比例`、`机构持股比例`
- ⚠️ **缺口**：机构持股明细与"近期增减持明细"可能不全。用"主力资金净流入（短期）+ 基金持股比例（中期）"做代理，并提示用户交叉核实。

### M — 大盘方向（zhishu）
```
上证指数 沪深300 创业板指 近20日涨跌幅
上证指数 均线 多头排列
```
- 可能字段：`涨跌幅`、`最新价`、`均线方向`
- ⚠️ **缺口**：**市场广度**（涨跌家数比、新高新低数量、累积/派发日）问财未必直接给。M 要素建议额外手工判断大盘是否处于"确认上升"。

## 复合初筛 Query（直接喂给 `--screen` 或 finance cli.py）

把 C+A+N 组合，一次拿到高质量候选池：

```
最近一季净利润同比增长大于25% 且 连续3年净利润同比增长 且 股价创52周新高
最近一季净利润同比增长大于40% 且 ROE大于15% 且 近一年涨幅大于50%
```

> 问财对"且"的自然语言连接支持较好。若复合 query 返回空，拆成单条件逐个查再取交集。

## 降级策略速查

| 情况 | 处理 |
|------|------|
| query 返回空 `datas` | `--call-type retry` 重试 → 简化 query（去掉复合条件）→ 改问法 |
| EPS 取不到 | 用"净利润同比"近似，注明替代 |
| RS Rating 取不到 | 用阶段涨幅百分位替代 |
| 机构明细不全 | 主力资金 + 基金持股比例代理 |
| 市场广度缺 | 手工查涨跌家数；M 仅用指数趋势 |
| 网关报"额度/次数超限" | 降低 `--limit`、减少 query 数、稍后重试 |
| 完全无法获取 | 引导用户访问 https://www.iwencai.com/unifiedwap/chat |

## 字段提取示例（供阅读 datas 时参考）

问财 `datas` 每行是一只股票，key 为中文字段名。常见身份字段：
- `股票代码`（如 `300750.SZ`）/ `code`
- `股票简称`（如 `宁德时代`）/ `股票名称`

辅助脚本会自动提取这两个字段作为行标识，其余字段按七要素关键字归类。
